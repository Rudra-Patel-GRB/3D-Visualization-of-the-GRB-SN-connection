# 3D-Visualization-of-the-GRB-SN-connection

Here we present the 3D interactive plot of the Type-II GRBs and the SNe connection. (A sample of the 3D Plots can be found in the main branch of the repository)

Along with the interactive 3D Plot, we have also created animation videos of the 3D plot for better visualization. 

For more reference about the datasets please visit our research article on the GRB-SN connection.
